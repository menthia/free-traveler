4. **도구 신뢰성 이슈(기록용)**: 이번 검증 과정에서 `edit_screens`(API)가 성공 응답과 구체적 DOM 변경 내역을 반환해도 `get_screen`/`list_screens`로 조회되는 화면 리소스에는 반영되지 않는 현상을 2건 모두에서 재현했다(즉시 확인 + 30초 + 90초 후 재확인, 총 3회 조회 모두 불변). 반면 **동일한 수정 요청을 Stitch 웹 UI에서 직접 입력했을 때는 정상 반영**되었다(`htmlCode` 파일 ID 변경으로 확인). 이는 이번 세션의 API 경로에 한정된 반영 지연/누락 이슈로 보이며, 향후 API를 통한 자동 수정 시 "성공 응답 = 실제 반영"으로 간주하지 말고 반드시 재조회로 확인해야 함을 시사한다.
