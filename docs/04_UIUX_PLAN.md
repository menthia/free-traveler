# Free Traveler — UI/UX Plan

- **Document ID:** UIUX-TRAVEL-001
- **기반 문서:** `01_PRD.md`, `02_SRS_BASELINE.md`, `PROJECT_SCOPE.md`, `03_UI_COVERAGE_ANALYSIS.md`, `design-reference/vendor/airbnb/DESIGN.md`
- **작성일:** 2026-09-17
- **상태:** UI/UX Design Baseline

> `design-reference/vendor/airbnb/DESIGN.md`은 여백·카드·타이포그래피의 **구조적 접근 방식**만 참고했다. Airbnb 고유의 색상 값(Rausch `#ff385c` 등), 폰트명(Airbnb Cereal), 워드마크·아이콘 등 상표적 요소는 그대로 사용하지 않고, Free Traveler 고유의 코랄 톤과 Inter 기반 타이포그래피로 재정의한다.

## 1. 공통 디자인 토큰

### 1.1 색상

| 토큰 | 값 | 용도 |
|---|---|---|
| `color.canvas` | `#FFFFFF` | 기본 배경(흰 배경) |
| `color.surface-soft` | `#F7F6F4` | 섹션 배경 구분용 은은한 톤 |
| `color.surface-strong` | `#F0EEEA` | 카드 내부 보조 배경, 비활성 필드 |
| `color.ink` | `#262425` | 제목·본문의 짙은 회색 텍스트(순검정 아님) |
| `color.body` | `#4B4749` | 긴 설명문 본문 |
| `color.muted` | `#78737A` | 캡션, 보조 라벨, 비활성 텍스트 |
| `color.hairline` | `#E4E0DC` | 구분선, 카드 테두리 |
| `color.coral` | `#FF6A4D` | 브랜드 포인트(주요 CTA, 활성 탭, 뱃지) |
| `color.coral-active` | `#E14E32` | 코랄 버튼 클릭 상태 |
| `color.coral-tint` | `#FFE3D8` | 코랄 비활성/배경 톤 |
| `color.on-coral` | `#FFFFFF` | 코랄 배경 위 텍스트 |
| `color.info` | `#1D5C8A` on `#EAF3FA` | 안전정보 일반 안내(코랄과 다른 청색 계열) |
| `color.warning` | `#9A5B12` on `#FFF3E1` | 여행경보 중대 단계, Stale 경고 |
| `color.error` | `#B3261E` on `#FDECEA` | 폼 검증 실패, 오류 화면 |
| `color.success` | `#1E7C4C` on `#E9F7EF` | 신고 접수 완료, 요청 처리 완료 |

코랄은 브랜드 CTA 전용으로만 쓰고, 경고·오류·안전 안내에는 색만으로 의미를 전달하지 않도록 **텍스트 라벨을 항상 병기**한다.

- **폰트:** `Inter, -apple-system, 'Apple SD Gothic Neo', 'Noto Sans KR', 'Malgun Gothic', system-ui, sans-serif` — 한글 본문은 Inter가 커버하지 못하는 글리프를 시스템 한글 폰트가 자동으로 대체한다.

| `type.display-xl` | 36px / 1.25 | 28px / 1.3 | 700 | Hero 제목 |
| `type.display-lg` | 26px / 1.3 | 22px / 1.35 | 700 | Section 제목(H2) |
| `type.display-md` | 20px / 1.4 | 18px / 1.4 | 600 | 카드 그룹 소제목 |
| `type.title-md` | 17px / 1.4 | 16px / 1.4 | 600 | 카드 제목 |
| `type.body-md` | 16px / 1.6 | 15px / 1.6 | 400 | 본문 설명 |
| `type.body-sm` | 14px / 1.5 | 14px / 1.5 | 400 | 카드 메타, 보조 설명 |
| `type.caption` | 13px / 1.4 | 13px / 1.4 | 500 | 라벨, 배지, 폼 캡션 |
| `type.button-md` | 16px / 1.25 | 16px / 1.25 | 600 | 버튼 라벨 |

### 1.3 spacing · radius · elevation

| 항목 | 값 |
|---|---|
| Spacing scale | 4 · 8 · 12 · 16 · 24 · 32 · 48 · 64 · 96px |
| Section 상하 여백(Desktop) | 64~96px |
| Section 상하 여백(Mobile) | 40~64px |
| Desktop 콘텐츠 최대 폭 | 1200~1280px (중앙 정렬, 좌우 여백은 뷰포트가 흡수) |
| Mobile 좌우 여백 | 20px |
| Card radius | 16px(`radius.lg`), 버튼 10px(`radius.md`), 배지/탭 999px(`radius.pill`) |
| Elevation | 단일 그림자 톤만 사용: `0 1px 2px rgba(38,36,37,0.06), 0 8px 20px rgba(38,36,37,0.08)` — 카드 hover·Drawer·Dropdown에만 적용, 나머지는 무광 |

### 1.4 브레이크포인트

| 이름 | 폭 | 기준 |
|---|---|---|
| Desktop 기준 | 1440px | 이 문서의 Desktop 레이아웃 수치는 1440px 뷰포트 기준으로 기록 |
| Mobile 기준 | 390px | 이 문서의 Mobile 레이아웃 수치는 390px 뷰포트 기준으로 기록 |
| Tablet(전환 구간) | 744~1128px | Card Grid 4열→2열, 좌우분할 유지, 상세 패널은 하단 Drawer로 전환 |

### 1.5 접근성 공통 규칙

- 모든 인터랙션 요소는 키보드 `Tab` 이동과 가시적 포커스 링(2px 코랄 또는 잉크 아웃라인, `outline-offset: 2px`)을 가진다.
- 버튼·탭·체크박스·아이콘 버튼의 터치 영역은 최소 44×44px을 확보한다(시각적 크기가 작아도 히트 영역은 44px로 확장).
- 색상만으로 의미를 전달하지 않는다. 안전 경보·오류·완료 상태는 항상 텍스트 라벨과 아이콘을 함께 표시한다.
- Drawer/Modal은 열릴 때 포커스를 내부로 이동시키고, `Esc`와 닫기 버튼으로 이전 포커스 위치로 복귀한다.

## 4. SCR-001 `/` 메인

Header 바로 아래부터 Footer 이전까지 7개 Section을 순서대로 배치한다. 1440px 기준 Hero는 화면 전체 높이를 차지하지 않고 약 560px로 제한해, 스크롤 없이도 Section 2(국내 인기 여행지)의 제목 줄이 보이게 한다.

### Section 1 — 여행지 검색 Hero
- **패턴:** Hero (전체 폭, 배경 `color.surface-soft`, 높이 Desktop 560px / Mobile 420px)
- **제목:** "어디로 떠날지, 지금 정해보세요"
- **설명(1~2문장):** "국내 10곳과 해외 15개국 30개 도시의 여행지를 테마와 계절로 찾아보고, 항공·숙소 조건은 여행 준비 페이지에서 한 번에 정리하세요."
- **콘텐츠:** 키워드 검색 입력(placeholder: "여행지, 국가, 테마로 검색"), 검색 결과는 같은 화면 하단으로 스크롤 이동
- **CTA:** 코랄 버튼 "여행 준비 시작하기" → `/travel-tools`(보조: 텍스트 링크 "동행 찾기" → `/mates`)
- **상태:** Success(검색 가능 상태)만 필요. 검색 결과 없음은 Section 2~3 목록의 Empty 규칙을 따른다.
- **관련 Requirement:** REQ-FUNC-003, 064, 067

### Section 2 — 국내 인기 여행지
- **패턴:** Card Grid (Desktop 3열×2행/최대 6열 가능, Mobile 1열)
- **제목:** "국내에서 먼저 둘러볼 여행지"
- **설명:** "가까운 국내에서 일정 부담 없이 다녀올 수 있는 여행지 6곳입니다."
- **콘텐츠:** 서울, 부산, 제주, 경주, 강릉, 전주 카드(카드 이미지 + `type.title-md` 지명 + 테마 배지 1~2개 + 추천 시기 한 줄). 이미지 alt 예시: `alt="제주 성산일출봉과 유채꽃밭 풍경"`
- **인터랙션:** 카드 클릭 시 같은 화면에서 여행지 상세 **Drawer**가 열린다(REQ-FUNC-004/006/007 콘텐츠 표시).
- **상태:** Loading(스켈레톤 카드 6개), Success(카드 6개), Error(목록 로드 실패 시 "여행지 정보를 불러오지 못했습니다. 다시 시도해주세요." + 재시도 버튼)
- **관련 Requirement:** REQ-FUNC-001, 002, 004, 007, 009

### Section 3 — 해외 인기 여행지
- **패턴:** Card Grid (Section 2와 동일 그리드지만 배경을 `color.canvas`로 바꿔 시각적으로 구분)
- **제목:** "다음 해외여행, 이 도시들은 어때요"
- **설명:** "15개국 30개 도시 중 처음 계획하기 좋은 도시 6곳을 모았습니다."
- **콘텐츠:** 도쿄, 방콕, 다낭, 파리, 뉴욕, 발리 카드(국가명 배지 + 도시명 + 테마 배지 + 추천 시기). alt 예시: `alt="태국 방콕 왓아룬 사원 야경"`
- **인터랙션:** SCR-001 내 Drawer로 상세 열람(안전정보 섹션 진입점 포함, Section 5로 연결).
- **상태:** Section 2와 동일한 Loading/Success/Error 구조
- **관련 Requirement:** REQ-FUNC-001, 002, 004, 006, 007, 008

### Section 4 — 여행 동기·테마로 찾기
- **패턴:** Chip 목록 (가로 스크롤 또는 줄바꿈 Chip, Desktop 8개 노출 / Mobile 가로 스크롤)
- **제목:** "이런 이유로 떠나는 여행이라면"
- **설명:** "자연·미식·가족·액티비티 등 여행 동기에 맞는 테마를 골라 여행지를 좁혀보세요."
- **콘텐츠:** 자연·힐링 / 도심 미식 / 가족 여행 / 액티비티·모험 / 문화·역사 탐방 / 나 홀로 여행 Chip 6개. Chip 클릭 시 Section 2·3의 목록이 해당 테마로 필터링되며 화면이 Section 2 위치로 스크롤된다.
- **상태:** 선택된 Chip은 코랄 배경 + `color.on-coral` 텍스트, 미선택은 `color.surface-strong` 배경
- **관련 Requirement:** REQ-FUNC-002

### Section 5 — 국가별 주의사항
- **패턴:** Card Grid (Desktop 3열×2행, Mobile 1열) + Drawer 연결
- **제목:** "출발 전, 국가별 주의사항을 확인하세요"
- **설명:** "치안·사기·법규·재난·보건 정보를 외교부 공식 출처와 최종 확인일과 함께 보여드립니다."
- **콘텐츠:** 일본, 태국, 베트남, 프랑스, 미국, 호주 카드(국가명 + 경보 단계 라벨 + 최종 확인일). 확인일이 7일을 초과하면 `color.warning` 배지 "최신 정보 재확인 필요"를 카드에 표시.
- **인터랙션:** 카드 클릭 시 같은 화면에서 안전정보 상세 **Drawer**(8개 카테고리, 외교부 링크, 긴급연락처, 면책 고지 포함)가 열린다.
- **상태:** Loading, Success, **Warning**(Stale 카드 강조), Error(안전정보 로드 실패 시 "안전정보를 불러오지 못했습니다. 외교부 해외안전여행에서 직접 확인해주세요." + 공식 링크)
- **관련 Requirement:** REQ-FUNC-006, 046~054

### Section 6 — 최근 동행글
- **패턴:** 데이터 있음: 3카드 Row(Desktop 3열, Mobile 1열) / 데이터 없음: 안내형 Empty State
- **제목:** "함께 떠날 동행을 찾고 있나요"
- **설명:** "최근 등록된 동행 모집글입니다. 조건이 맞는 동행이 있는지 살펴보세요."
- **콘텐츠(Success):** 모집글 3개 카드(국가·지역, 기간, 모집 인원, 여행 스타일 배지, "모집중" 상태)
- **콘텐츠(Empty):** 제목 "아직 등록된 동행글이 없어요" + 설명 "가장 먼저 동행 모집글을 올려보세요. 참가자는 비공개 메시지로만 요청을 보낼 수 있어 연락처가 노출되지 않습니다." + 이용 방법 3줄 요약(모집글 작성 → 참가 요청 대기 → 승인 후 대화 시작) + CTA "동행글 작성하기" → `/travel-tools`(동행 탭)
- **CTA(공통):** "동행 더 보기" → `/mates`
- **상태:** Loading(카드 3개 스켈레톤), Success, Empty(위 설명), Error(목록 로드 실패 안내+재시도)
- **관련 Requirement:** REQ-FUNC-030, 031

### Section 7 — free_traveler 요약
- **패턴:** 좌우분할(Desktop: 좌 46% 인물/여행 사진, 우 54% 텍스트+통계+CTA / Mobile: 사진 위, 텍스트 아래로 세로 스택)
- **제목:** "50번 넘게 떠난 사람이 고른 여행지"
- **설명:** "`free_traveler`는 50회 이상의 자유여행으로 30개국 이상을 경험하며 이 여행지들을 직접 검증했습니다."
- **콘텐츠:** `50+ Trips` / `30+ Countries` 수치 배지 2개 + 한 줄 철학 인용구
- **CTA:** "대표 소개 더 보기" → `/about`
- **상태:** Success만 필요(정적 콘텐츠)

## 6. SCR-003 `/travel-tools` 통합 여행 준비

항공편 / 숙소 / 동행 구하기 3개 탭은 **입력·검증·완료 상태를 독립적으로 유지**한다. 한 탭에서 입력 중인 값은 다른 탭으로 이동해도 사라지지 않지만, 각 탭의 검증 오류와 완료 상태는 서로 영향을 주지 않는다.

### Section 1 — Intro(이용 순서 3단계)
- **패턴:** 3단계 안내
- **제목:** "여행 조건을 먼저 정리하고 이동하세요"
- **설명:** "이 페이지는 조건 정리를 돕는 곳이며, 실제 예약은 이동한 외부 사이트에서 진행됩니다."
- **3단계:** ① 국가·지역·날짜 입력(또는 동행 조건 작성) → ② 요약 확인 → ③ 외부 사이트 이동 또는 동행글 게시
- **상태:** Success만 필요
- **관련 Requirement:** REQ-FUNC-015, 023, 054

### Section 2 — 탭: 항공편 / 숙소 / 동행 구하기
- **패턴:** 탭(Segmented Tab, Desktop 가로 배치 / Mobile 가로 스크롤 가능한 탭바)
- **설명:** 각 탭 아래에 한 줄 설명을 붙인다. 항공편 — "국가·지역·날짜를 정리하고 항공 사이트로 이동합니다." 숙소 — "숙박 국가·지역·기간을 정리하고 숙소 사이트로 이동합니다." 동행 구하기 — "일정이 맞는 동행을 모집하는 글을 작성합니다."
- **상태:** 활성 탭은 코랄 밑줄 + 잉크 텍스트, 비활성은 `color.muted`
- **관련 Requirement:** REQ-FUNC-011, 019, 031

### Section 3 — 조건 입력 Form (항공/숙소 탭 전용)
- **패턴:** Form(2단 Desktop: 국가/지역 좌, 날짜 2개 우 / Mobile 1단)
- **항공 탭 필드:** 국가, 지역·도시(국가 선택 시에만 옵션 활성화), 출발일, 귀국일
- **숙소 탭 필드:** 국가, 지역·도시, 체크인, 체크아웃
- **검증:** 과거 날짜·역전된 날짜 입력 시 해당 필드 아래 `color.error` 텍스트로 즉시 표시하고 다음 단계 버튼을 비활성화
- **상태:** Loading(국가 목록 불러오는 짧은 순간), Success(유효 입력), **Error**(날짜 검증 실패)
- **관련 Requirement:** REQ-FUNC-011, 012, 013, 019, 020, 021

### Section 4 — 입력 요약 + 외부 이동 Action Card (항공/숙소 탭 전용)
- **패턴:** 좌우분할(Desktop: 좌 요약 텍스트, 우 Action Card / Mobile: 세로 스택)
- **설명:** "입력하신 조건을 다시 확인하세요."
- **콘텐츠:** 국가·지역·날짜 요약 리스트 + Action Card(코랄 버튼 "항공편 보러 가기" 또는 "숙소 보러 가기", 새 탭 이동 안내 아이콘)
- **상태:** Success(요약 표시), Success-이동됨(버튼 클릭 후 "새 탭에서 열렸습니다" 토스트), **Error**(외부 URL 설정 오류 시 "지금은 이동할 수 없습니다. 잠시 후 다시 시도해주세요." + 재시도 버튼)
- **관련 Requirement:** REQ-FUNC-014, 016, 017, 018, 022, 024, 025, 026

### Section 5 — 비전달 고지 + 이용 Tip
- **패턴:** CTA Banner형 정보 배너 + Tip 3개 Chip/List
- **고지 문구(항상 노출):** "입력하신 국가·지역·날짜는 외부 사이트로 전달되지 않으며, 서버에도 저장되지 않습니다."
- **항공 Tip 3개:** "출발·귀국 요일에 따라 가격 차이가 크니 하루 앞뒤로도 비교해보세요." / "경유 여부에 따라 총 이동 시간이 크게 달라집니다." / "수하물 규정은 항공사마다 다르니 이동한 사이트에서 다시 확인하세요."
- **숙소 Tip 3개:** "숙소 위치는 지도에서 실제 도심까지의 거리로 다시 확인하세요." / "체크인·체크아웃 시간이 항공 일정과 맞는지 확인하세요." / "취소 정책은 예약 전 반드시 원문에서 확인하세요."
- **상태:** Success만 필요
- **관련 Requirement:** REQ-FUNC-015, 023

### Section 6 — 동행 구하기 탭(로그인 안내 또는 작성 Form + 안전 안내)
- **패턴:** 탭 상태에 따라 두 가지 구성 중 하나
  - **비로그인/성인 확인 미완료(Unauthorized):** 안내 Card — "동행 모집글은 이메일 인증과 성인 확인을 완료한 회원만 작성할 수 있습니다." + 버튼 "로그인/가입하기"(`/account`)
  - **로그인 + 성인 확인 완료(Success):** 작성 Form — 제목, 국가, 지역, 시작일·종료일, 모집 인원, 선호 조건, 여행 스타일, 상세 설명, 안전수칙 동의 체크박스 + 게시 버튼
- **연락처 탐지:** 본문에 전화번호·이메일·메신저 ID 패턴이 감지되면 제출을 막고 "연락처로 보이는 내용이 있어 게시할 수 없습니다. 해당 부분을 수정해주세요."를 표시(**Error**)
- **안전 안내(항상 노출):** "이 서비스는 신원이나 안전을 보증하지 않습니다. 참가 요청은 비공개로만 전달되며, 문제가 있으면 신고·차단을 이용하세요."
- **상태:** Unauthorized, Loading(제출 중), Success(게시 완료 후 "동행글이 등록되었습니다" 토스트 + `/mates` 이동 링크), **Error**(연락처 탐지, 필수값 누락)

  - **Error**(중복 요청 "이미 이 모집글에 참가를 요청했습니다", 마감된 글에 요청 시도 "마감된 모집글입니다")
  - Success-완료(요청 접수 후 "참가 요청을 보냈습니다" 토스트, 상태는 화면 안 배지로 유지 — 실제 이메일 발송 없음)
- **관련 Requirement:** REQ-FUNC-033, 034, 035, 036, 037, 039, 040, 043

### Section 5 — 동행 신청 방법
- **패턴:** 3단계 안내
- **제목:** "참가 요청은 이렇게 진행됩니다"
- **3단계:** ① 모집글에 비공개 메시지로 참가 요청 → ② 작성자가 승인 또는 거절 → ③ 승인되면 화면 안 알림으로 확인, 이후 대화는 두 사람이 직접 조율
- **상태:** Success만 필요
- **관련 Requirement:** REQ-FUNC-034, 036, 043

### Section 6 — 안전 안내 + CTA Banner
- **패턴:** CTA Banner
- **안내 문구:** "이 서비스는 신원이나 안전을 보증하지 않습니다. 공개 연락처를 요구하거나 불편함을 주는 상대는 신고·차단해주세요."
- **콘텐츠:** 신고·차단 방법 요약(상세 패널 내 버튼 위치 안내)
- **CTA:** "항공·숙소 조건도 정리해보세요" → `/travel-tools`
- **상태:** Success만 필요
- **관련 Requirement:** REQ-FUNC-039, 040, 080
