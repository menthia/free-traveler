# MANUAL-A11Y-CHECK 체크리스트 (REQ-NF-023)

핵심 흐름(검색, 폼 입력, 모달/Drawer 닫기, 참가 요청 제출)을 **키보드만으로** 완료할 수
있는지 확인한다. 전체 Use Case 정식 스크린리더 QA는 범위 밖(REQ-NF-025 EXCLUDED)이며,
핵심 흐름만 확인한다.

## 1. 사전 자동 확인 결과 (참고용 — 사람 확인을 대체하지 않는다)

Playwright로 여행지 Drawer를 Tab+Enter로 열고 **Esc로 닫히는지** 확인하는 과정에서, Esc
키 지원이 실제로는 구현되어 있지 않다는 것을 발견했다(`design-reference/D-001/DESIGN.md`
§11 "Esc와 닫기 버튼으로 이전 포커스 위치 복귀" 요구사항 누락). 아래 세 Drawer에 Esc로
닫는 기능을 추가했다(포커스 트랩·포커스 복귀까지는 이 Task의 승인된 축소 범위 밖이라
하지 않음 — 닫기 버튼을 Tab으로 찾아 Enter로 닫는 것은 이미 가능하다):

- `src/components/home/DestinationDrawer.tsx`
- `src/components/home/SafetyDrawer.tsx`
- `src/components/mates/MateDetailDrawer.tsx`

수정 후 Playwright로 재확인: Tab으로 여행지 Card에 포커스 → Enter로 Drawer 열림 → Esc로
Drawer 닫힘, 정상 동작 확인함.

## 2. 사람이 직접 확인할 핵심 흐름

아래 항목을 **마우스를 쓰지 않고** Tab / Shift+Tab / Enter / Space / 방향키 / Esc만으로
완료해 주세요. 포커스가 어디 있는지 보이지 않거나(포커스 링 없음), 순서가 이상하거나,
막혀서 다음 요소로 못 넘어가는 곳이 있으면 메모해 주세요.

- [ ] **검색(SCR-001 `/`)**: 국가 필터 select와 도시·계절 검색 input을 Tab으로 찾아
      값을 바꿀 수 있다.
- [ ] **여행지 Drawer 열기/닫기(SCR-001 `/`)**: 여행지 Card를 Tab+Enter로 열고,
      Esc 또는 닫기 버튼(Tab+Enter)으로 닫을 수 있다.
- [ ] **안전정보 Drawer 열기/닫기(SCR-001 `/`)**: 국가별 주의사항 Card를 Tab+Enter로
      열고, Esc 또는 닫기 버튼으로 닫을 수 있다.
- [ ] **폼 입력(SCR-003 `/travel-tools`)**: 항공 탭에서 국가·지역·출발일·귀국일을
      Tab으로 순서대로 이동하며 입력할 수 있다.
- [ ] **동행글 작성 Form(SCR-003 `/travel-tools`, 로그인 필요)**: 제목부터 안전수칙
      동의 체크박스까지 Tab으로 순서대로 입력하고 Enter/Space로 제출할 수 있다.
- [ ] **참가 요청 제출(SCR-004 `/mates`, 로그인 필요)**: 동행글 상세를 열고 참가 요청
      메시지 입력 후 Tab+Enter로 제출할 수 있다.
- [ ] **동행글 상세 Drawer 닫기(SCR-004 `/mates`, Mobile 폭)**: Esc 또는 닫기 버튼으로
      닫을 수 있다.

## 3. 확인 결과

사용자가 직접 확인 — 로그인이 필요한 두 항목(동행글 작성 Form, 참가 요청 제출)은 계정이
없어 확인하지 못함(남은 항목). 나머지 항목은 모두 통과. 확인 중 실제 버그 발견:
여행지 Card를 Tab으로 포커스해도 포커스 링이 보이지 않음 — `DestinationCardGrid.tsx`의
Card wrapper `overflow-hidden`이 outset 포커스 링을 잘라내던 것이 원인. `outline-offset-2`
를 `-outline-offset-2`(인셋 링)로 수정해 해결하고 스크린샷으로 재확인함.

**남은 항목(추후 로그인 계정으로 확인 필요)**:
- [ ] 동행글 작성 Form(SCR-003) 키보드 완주
- [ ] 참가 요청 제출(SCR-004) 키보드 완주
